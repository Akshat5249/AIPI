# Dashboard gallery

These unedited screenshots were captured from the running local Docker lab on
2026-10-14, using the deterministic mock. A real checkout fault was recovered,
its incident created in the browser, and the report evaluated without manual DB
edits. Original milestone labels, incident titles and IDs remain visible; the
images are examples, not a hosted service or fresh-run results.
