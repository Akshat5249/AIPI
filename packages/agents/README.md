# Agents

`Workflow` compiles the six-node LangGraph with strict Pydantic state, nested
spans, durable node/tool events and one explicit report-repair edge. The adapter
interface validates structured output and usage; the default mock reasons only
from full-scope deterministic correlator signals, with no network/key required.
Optional paid providers are deferred and fail explicitly if selected.

Pure verification preserves supporting and contradicting evidence families.
Scoring uses the exact AIPI_CONTEXT section-8 formula, never model confidence.
Facts retain complete full-scope rule witnesses beyond the display cap; all
structured/Markdown citations must resolve within the scoped evidence input.
Recommendations are approval-required read-only checks and never execute.

Synthetic bundles are authored separately from hidden scorer truth. Golden tests
run both the pure offline path and the actual LangGraph, including poisoned logs.
The API supervisor persists artifacts and serves status, SSE and scoped lookup.
